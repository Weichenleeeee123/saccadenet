# SaccadeNet：大画幅小目标搜索的语义计算与感知成本

状态：方法与模型已冻结；正式E1运行中。结果段在逐局质量检查和图4/5生成后填写。本文不把开发冒烟数字写成正式结论。

## 问题与可检验主张

任务是在一张RGB画布中，从公开的`K=12`张192×192卡片里找出恰好一张含查询数字的卡片。数字来自MNIST，原始28×28缩放至48×48，位置有±4px抖动。四种画幅为1920×1080、3840×2160、7680×4320、15360×8640；卡片大小保持像素不变。模型输出坐标，离真实目标中心48px内算命中。此合成任务隔离了“画幅增长但目标局部信息固定”的变量，不代表一般自然图像检索能力。[数据来源与拆分](EXPERIMENT_PROTOCOL.md)、[MNIST官方说明](https://yann.lecun.org/exdb/mnist/index.html)。

预注册G1问的是：在这四档、固定K下，SaccadeNet的**语义计算**从1080p到16K是否增加不超过4倍，同时准确率下降不超过3个百分点。感知前端仍需读原图、建金字塔，不能声称总计算或延迟与图幅无关。G2问的是一段式缩图何时因数字小于独立标定的最小可读尺寸而失效。阈值是验收目标，不是保证成立的定理。

## 视网膜与成本边界

原图仅交给传感器。它构建2×2抗混叠平均金字塔，再对每个注视点输出96×96高清中央凹及128角扇区的对数极坐标外围样本。取`Δ=2π/128`、`r_j=48·exp(jΔ)`，选与半径对应的金字塔层后双线性采样；最后一环覆盖到画布对角距离。离散环数为79/94/108/122，每眼含中央凹的样本数为19,328/21,248/23,040/24,832。原V0.1的环数少计一个端点，修正见[D18](DECISIONS.md)。

环数随最大半径对数增长，因此**每眼输出样本量**是对数尺度；初始金字塔的全图读写仍随像素数增长。固定K且注视次数受控时，后端语义工作可相对平缓，但候选检测、重建、CNN、融合和路由都须计入。RAM已有多尺度局部高分辨率glimpse，[原论文](https://proceedings.neurips.cc/paper/2014/file/09c6c3783b4a70054da74f2538ed47c6-Paper.pdf)是直接前例；本项目不以“首次局部注意”作为贡献。对其尺度数随覆盖半径对数变化的描述是由论文的逐级patch构造作出的推断，不是其直接发表的复杂度证明。

本项目分别报告`C_sensing`（金字塔、采样、缩放的解析运算估计和读取字节）与`C_semantic`（检测、反投影、共享CNN、融合与策略的解析运算估计）。CNN卷积按1 MAC=2 FLOPs计；OpenCV缩放/连通域等不是硬件精确指令profile。墙钟、峰值RAM和CUDA分配另列，不与FLOPs相加。全分辨率滑窗还另列分块halo重复计算的实际估计与理想单次dense解析值。[成本决策](DECISIONS.md)、[实验协议](EXPERIMENT_PROTOCOL.md)。

## 观测、融合和搜索

检测器只读`RetinaOut`中的亮区域，通过外围sample坐标反投影候选中心；不能拿原图或真值补候选。对候选的96×96视图也仅由已采样的中央凹/外围插值。共享11类CNN给查询数字相对其他10类的log-odds。独立calibration拆分按偏心率拟合`μ0(e), μ1(e), σ(e)`和`d′(e)=(μ1−μ0)/σ`。低辨别力或无效mask不更新后验。

固定融合B为每个候选保存质量最高的一眼，`D_i=max_t d′(e_it)^2`，`LLR_i=D_i(x_i*−1/2)`，其中`x_i*=(score_i−μ0)/(μ1−μ0)`取达到最高质量的观测。新候选从中性证据进入，重复同质量观测不累加。此形式只在高斯共享方差近似和标定适用域内可解释；确定性静止画面同位置重看没有独立新噪声，故没有采用每眼LLR相加。相邻坐标大幅更新时重置旧候选证据，避免把旧位置分数绑定新卡。

每一步计算候选中心与近邻中点组成的有限注视集合，按`G(k)=Σ_i p_i[d′²(e_ik)−D_i]_+`选择下一眼，缺少足够候选时遍历固定5×5锚点。它借鉴[ELM的检测力平方加权思想](https://pubmed.ncbi.nlm.nih.gov/19138697/)，但这里的`G`是明确的工程启发式，**不是**精确Shannon熵减。后验只对已发现候选归一化；公开K=12使停机条件设为至少发现12个候选且有证据、最大后验≥0.95，否则到40眼或探索耗尽。误检凑够K仍会导致过早停机，阈值不是全局置信保证。理想搜索的理论源头见[Najemnik & Geisler 2005](https://www.nature.com/articles/nature03390)。

## 四种比较方法

SaccadeNet-lite使用上述视网膜、融合B与增益路由。全分辨率基线用同一个CNN以步长16扫描每个合法96×96窗口，按输出格分块并覆盖边缘，选查询分数最高的位置；没有真值候选捷径。一段式基线先抗混叠缩到宽1024，再用同网络全图密集扫描。两阶段基线在1024宽缩图用亮卡连通域找候选，按粗查询分数排序，随后逐个读原图96×96 crop；高清查询概率经calibration集250局的Platt拟合，≥0.95停，若从未过阈值则从已看候选中选最高。两阶段标定用精确中心crop，运行时粗检测位置会偏，校准迁移有限制。

四方法共享v1权重（SHA256与配置见[交接](HANDOFF.md)）；MNIST train前50,000仅训练，后5,000 calibration、再5,000 development，官方test仅用于冻结后最终E1。各方法每档100个相同画布种子，唯16K全分辨率基线预注册前20个，共1,520局。失败和OOM保留在准确率分母；成本记录实际可得值，缺条件不补点。正式图4/5将由保存的`episodes.csv`自动生成，显示每个点的n与区间。16K全分辨率与其他方法的配对比较只用共同20种子。

## 讨论与答辩短答

**前端是否读全图？** 是。初始金字塔读取全图，所以本项目只主张语义计算可随图幅增长较慢；报告分列前端读字节、解析感知运算、语义运算与时间。

**网络创新在哪里？** 11类CNN本身不是新结构。工程问题是将受限视网膜、Level 2候选发现、偏心率标定、避免重复计证的融合与成本可审计的停止/路由连成闭环。效果必须由图4/5和误差分解证明。

**与RAM的关系？** RAM已有局部多尺度glimpse和可控制语义计算，本项目对单眼采样律、固定金字塔前端成本、静态重复观测融合与四档分辨率协议作可检验组合，不主张先于RAM。[核验文献](references.md)。

**与粗到细两阶段相比？** 两阶段可一次缩图发现全部候选，再只做少量高清crop，可能更快或更准。本项目把它列为必跑基线；若它胜出，报告其准确率/成本、搜索密度与前端读取条件，不改称“优于所有方法”。

边界：这是固定K、恰一目标、已知查询、合成MNIST卡片；Level 2后验未显式建模“目标尚未发现”，静态重复画面与高斯拟合存在偏差。独立最终测试可检验工程现象，不能独自支持强生物学或广泛自然图像结论。
