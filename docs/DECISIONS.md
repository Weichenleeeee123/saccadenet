# 决策与待验证假设

日期：2026-09-25。原始来源为 V0.1；本文件补充执行层面的默认方案，不修改来源文档。状态“计划采用”表示实现时需验证，绝不代表已证实。

| ID | 状态 | 决策 / 原因 / 验证方式 |
|---|---|---|
| D01 | 本轮生效 | 只交付规划与本地 Git；不实现、不训练、不下载数据、不创建远端。保留所有文件。 |
| D02 | 计划采用 | 以 V0.1 的 P0 为主线；V0 为历史。比较“直接全做”“先打通 P0”“只做理论”后选先 P0：可验证性与 56 小时风险最平衡。 |
| D03 | 计划采用 | 核心循环不接收真值 `meta`。`EpisodeInput` 只含 query、画布尺寸、公开 K；模型只能接触 `RetinaOut`。Level 1 用单独的已知候选入口。离线数据生成/训练/评测可读标签，推理不可读。以接口检查、运行时真值访问陷阱测试验证。 |
| D04 | 计划采用，偏离原伪代码 | Level 2 的后验只在已发现候选上归一化。利用任务公开 K=12，至少发现 K 个去重有效候选且存在有效观测后才允许阈值停机；未达门槛继续探索，T_max 后正常计失败/最终回答。记录门槛、候选数、终止原因；不宣称此门槛消除了漏检或提供全局 95% 校准。误检凑够 K 仍是风险。所有方法获得相同公开 K；另存不加门槛的开发集诊断，正式配置在 E1 前冻结。 |
| D05 | 计划采用 | 候选为空或未够 K 且所有增益≤数值容差时，在预先生成的 4×4 画布均匀锚点中选未访问点，按距当前点、x、y 排序打破平局；锚点用完则终止 `search_exhausted`。锚点只依赖尺寸、不读真值、不做图像判断；每次均重新走视网膜并记账。若开发召回不足，调整规则须重新冻结，禁止测试集调参。 |
| D06 | 计划采用 | 训练源 MNIST train 的前 50,000 个索引用于训练，后 10,000 用于标定/开发并按记录的子集再拆；MNIST test 只用于最终 E1。画布与源数字都分离；所有生成清单记录原始 digit ID，测试 digit 可跨测试画布复用但不得进入训练。 |
| D07 | 计划采用 | 源方案的检测未指定算法：先做视网膜样本的亮度/局部对比度阈值、极坐标连通域、角度首尾连接、坐标反投影与中心合并。阈值只用开发集选择；召回与定位误差是 S2/T05 首要门槛，不能以真值补候选。 |
| D08 | 计划采用 | 去重半径默认 96 px；评测一对一匹配半径 48 px，同时报告定位误差≤20 px 的比例（96 crop 内容纳48数字及±4抖动的余量）。发现候选允许用后续视网膜观测细化位置；坐标变化>8 px 时清空该候选融合状态，并记录事件，防止旧坐标质量与新坐标混用。开发集验证后冻结。 |
| D09 | 计划采用 | 核心用相同 11 类小 CNN，包含空背景、局部数字、偏心增强；全卷积滑窗使用卷积/池化头，按 halo 分块，分块结果必须与小图整图推理一致。不能用 K 个真值 crop 冒充全分辨率基线。 |
| D10 | 计划采用 | CNN 使用 1 MAC=2 FLOPs；感知、检测、反投影、CNN、信念/路由分别记账。比较/索引等非 FLOP 操作单列，不与 FLOPs 不加说明直接相加；报告共同单位浮点运算总量及额外操作向量、延迟、内存。补足原方案易漏掉的检测与重建成本。 |
| D11 | 计划采用 | E1 融合 B、增益策略、τ=.95、T_max=40、K=12、c=0；四分辨率每方法每条件100局。16K全分辨率基线至少20局，使用100局中的预注册前20个种子，图中显式标n。不能用20局支持精确的3个百分点差异结论。 |
| D12 | 计划采用 | 单人作为排期默认，H0从后续实施开始计；本轮规划时间不自动算入56小时。H46前完成最小回放代码，H46后仅写报告、排练、允许记录在案的阻断修复。 |
