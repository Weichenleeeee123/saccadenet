## S1：玩具策略门禁

运行`.venv\Scripts\python.exe -m scripts.spikes.policy_toy --trials 200`，原始CSV见`reports/spikes/policy-toy-20260925T153330636486Z.csv`。固定随机种子100000起、四候选稀疏800px方阵和密集150px方阵；`d′(e)=4exp(−e/140)`，阈值.95，上限15眼。A每眼独立噪声并累积证据；B每候选只留最高质量眼；C每候选固定共享噪声方差.04、每眼新残差并用相关模型融合。两策略只改变下一注视点，目标与噪声seed配对。

| 观测模型 | 稀疏：增益 / MAP平均眼数 | 密集：增益 / MAP平均眼数 | 结论 |
|---|---:|---:|---|
| A | 3.56 / 3.435 | 1.94 / 1.94 | 无稳定优势 |
| B | 3.72 / 4.415 | 2.155 / 2.67 | 相对MAP少15.7% / 19.3%，均未达预设20% |
| C | 3.64 / 3.75 | 1.935 / 1.94 | 稀疏小幅优势、密集基本相同 |

因此降级策略卖点，不声称≥20%扫视优势，更不把玩具结果等同E1实际性能。没有为追阈值增删布局或调`d′`；200试次和固定布局只作可行性筛查，正式策略比较需另立配对E3。

## S4：60秒口头说明草稿

**两层成本。** 每次实验先把整张图变成固定抗混叠金字塔，这一步确实随图片变大而更贵。之后网络每眼只读一小份视网膜样本，后端判断数字的计算量可以增长得慢。图4画后端语义FLOPs，表格同时公开前端读字节、感知估计与时间，避免“总成本恒定”的误导。

**网络原语。** 96px中央凹看清数字，128方向的对数半径外围寻找亮卡；反投影和CNN只能使用采到的像素。已发现候选的偏心率决定证据质量，重复看到同一位置不把完全相同的信息当作多次独立证据。绿真值圈只在离线评分/回放最后出现，不进主循环。

**与RAM。** RAM早有局部多尺度glimpse，[2014原论文](https://proceedings.neurips.cc/paper/2014/file/09c6c3783b4a70054da74f2538ed47c6-Paper.pdf)已支持计算与整图规模分离的主张。本项目差别在连续对数极坐标采样律、前端/后端分账、固定静态画面的证据处理和1080p→16K同任务实测；不说“第一个局部视觉网络”。

**与两阶段。** 把全图缩到1024再找卡、逐个读高清原图是一条很强的基线，可能更快更准。我们让两条方法共享CNN和画布，记录两阶段每次高清crop，正式图如实呈现谁胜出。其价值是帮评委看清“主动视网膜何时值得”，不是保证获胜。
